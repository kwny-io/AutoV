# 客户配置

按租户的版本化策略与模板。**不含任何密钥。**

## 约定

```
customer-configs/<tenant>/
  policy/          自动化策略（四档模式 + 双开关 + 覆盖）
  templates/       导演 DSL 模板引用
  bindings/        资产绑定默认值
```

模板在 `_template/`。

## 不能放这里

- API key、BYOK 凭证、音色样本
- 任何形式的密钥

密钥走密钥管理服务，配置里只留引用。

## 策略继承

企业 → 项目 → 集/run → 阶段 → 节点。

**只允许收紧，不允许放宽。** 节点级覆盖不能突破企业级下限。
