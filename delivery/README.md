## 业务 KPI

| 指标 | 含义 |
|---|---|
| 成片可用率 | 通过验收的成片分钟占比 |
| 首轮镜头可用率 | 第一次生成就通过的镜头占比 |
| 每可用分钟成本 | 总花费 ÷ 可用成片分钟 |
| 单集交付耗时 | 从开工到交付 |
| 返工率 | 需要返工的镜头占比 |
| 人工干预 | 人工介入次数与时长 |
| 记忆正确性 | 跨集事实的一致程度 |
| 毛利 / ROI | 收入与成本 |

## 标准交付物

Master、SRT/VTT/ASS 字幕、分轨 stems、EDL、manifest、QC 与审计证据、成本报告、记忆 checkpoint、完整性签名。

**正式 Master 必须满足完整性门。** 缺素材的包要明确标注包类型，不能冒充正式交付。

## E40

FDE 移交需要客户验收、培训、值班、容量与责任边界**签字**。没签字不算交付完成。
