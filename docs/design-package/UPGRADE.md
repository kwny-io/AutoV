# v2升级摘要

v0.1的单体、共享业务数据库和粗粒度边界已被企业服务架构取代。

- 48个独立服务，每服务数据所有权、部署、API/事件、扩容、恢复和专项验收。
- 跨集正史、上下文、连续性分别独立，支持知情状态、伏笔、双时间、分支和前集改稿传播。
- 四档人工参与、生成与接受两开关、逐级覆盖；实时权限与预算不被旧快照绕过。
- 版本接受、预算、配额、任务分别唯一权威；准入Saga、Outbox/Inbox、UNKNOWN提交保守对账。
- node_epoch局部版本与execution_fence取消/切主分开；不因单镜修改废掉所有在途任务。
- 地域cell、多租户/专属部署、SSO/BYOK、驻留、审计、发布兼容、恢复演练与经营验收。

仅修改了设计与静态产物，没有运行业务系统或调用付费模型。实施读取README、DESIGN、服务规格与contracts，旧版仅保留历史参考。
